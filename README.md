## 開発で大切にしていること

- **使う場面から考える。** エディタやゲーム、制作の流れの中で、何ができるようになるかを起点にする。
- **仕組みまで掘り下げる。** アプリだけでなく、それを支える解析・通信・データ管理にも取り組む。
- **確かめたことを伝える。** 動作確認できた範囲と制約を、コード・テスト・ドキュメントに残す。
